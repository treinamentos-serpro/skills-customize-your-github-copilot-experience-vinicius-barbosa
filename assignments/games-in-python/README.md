
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo de adivinhar palavras em Python, praticando manipulação de strings, loops, condicionais, entrada de dados do usuário e seleção aleatória.

## 📝 Tarefas

### 🛠️ Implementar o jogo da Forca

#### Descrição
Crie um jogo da Forca em que o jogador adivinhe letras para revelar uma palavra oculta antes que as tentativas incorretas se esgotem.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatoriamente de uma lista predefinida.
- Aceitar palpites de letras do jogador.
- Mostrar o progresso atual da palavra no formato `_ _ _`.
- Rastrear e exibir o número de tentativas incorretas restantes.
- Encerrar quando a palavra for adivinhada ou quando as tentativas se esgotarem.
- Exibir uma mensagem informando se o jogador venceu ou perdeu.
